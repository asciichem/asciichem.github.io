AsciiChem is an ASCII syntax for representing **chemistry** — atoms, molecules,
bonds, reactions, electron configurations, and the embedded mathematics
that chemistry publications rely on. It is to chemistry what **AsciiMath** is
to mathematics, but with a semantic model underneath: every parse produces
the same tree, regardless of which front door you came in by.

## One model, four implementations

Four independent packages — `asciichem` (Ruby, the reference),
`asciichem` (TypeScript), `asciichem-py` (Python), and `asciichem-rs`
(Rust) — implement the same model and pass the same
[shared corpus](https://github.com/asciichem/asciichem-tests).
Pick whichever ships in your stack:

## Why four

A molecule has one structure regardless of the notation you write it in:
InChI, SMILES, molfile, or AsciiChem. Likewise, the *AsciiChem model* has
one shape regardless of the language you run it in. Four implementations
keep the contract honest — no single implementation's shortcuts become the
specification.
